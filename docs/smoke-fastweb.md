# Fastweb API smoke test (PLT-07)

Closes OQ-2. OQ-3 (ASR) stays open: no Whisper key, deferred to ASR-01 (`docs/PLAN.md` §4).
Re-run: `backend/.venv/bin/python scripts/smoke_fastweb.py` (about 3 min, a few cents of credit).

## Findings

- **Access.** One OpenAI-compatible base URL, **one key per model**: a key used with another
  model gets 404, and `GET /v1/models` answers 401 for every key. Keys live in
  `.secrets/fastweb_keys.json` (`{model_id: key}`, gitignored) and `Settings.api_key_for(model)`
  picks the right one. `bpod1.ai-factory.fastweb.it` answers the same as `spod`.
- **Keys expire 2026-10-25 00:00 UTC** (JWT `exp`). Record everything the demo needs with
  `LLM_MODE=record` before then; after that only `replay` works without new keys.
- **Model id.** Qwen3.8 is `Qwen/Qwen3.8-27B-FP8`; the guide's `Qwen/Qwen3.8-27B` gets 404.
  `Qwen/Qwen3.5-397B-A17B-FP8` is available although the guide doesn't list it.
- **Tool calling works on all 5 chat models**: real `tool_calls`, correct arguments, result used
  in the follow-up answer.
- **Structured output (for PLT-05 `extract`)**:
  - Send the schema with `$defs` **inlined**. With Pydantic's `$ref`, Gemma drops required
    fields of the nested object (`invalid`).
  - Use `tool_choice="required"`: it worked on every model. With `auto` the Qwen models sometimes
    answer in text (`no_tool`). Forcing by function name is accepted but not reliable on Qwen3.8.
  - Keep the Pydantic validation and the one retry anyway: n is small.
- **Reasoning models** (Qwen 3.5/3.6/3.8, GLM) return a `reasoning` field and spend 100–250
  tokens on it even for "say ok": with a small `max_tokens`, `content` comes back empty. Gemma
  has no reasoning.
- **Embeddings** work with `dimensions` 512 and 2048; an Italian/English paraphrase scores
  clearly above an unrelated sentence. 512 is enough to start (RFC §4.7.1).

## Decision

Chat model: **`google/gemma-4-26B-A4B-it`** (EU hosting, no reasoning overhead, 0.1–0.6 s per
call, 3/3 valid extractions with inlined schema and `required`). Fallback for hard cases:
`glm-5.3-flash` or `Qwen/Qwen3.5-397B-A17B-FP8` (also 3/3 with `auto`, 4–6 s, hosted outside the
EU: declare it if used). Embeddings: `Qwen/Qwen3-VL-Embedding-2B`, `dimensions=512`.
