# Systems sources – answer key (`generated/sources/systems/`)

Generated by `generator/systems/run_all.sh` (deterministic; `PYTHONHASHSEED=0`). Shared facts (PO numbers, ETAs, quantities,
ID crosswalks) live in `generator/systems/common.py`; every area imports it so the systems agree with each other and with
`generated/sources/erp/` (shipments, store stock, POS, forecast) and `generator/events.py`.

## Folder map

| Folder | Native style | Main content |
|---|---|---|
| `warehouse/` | SAP EWM/ERP extracts (IT10, US20) + 3PL portal files (HK30) | daily DC stock by storage location, goods movements, deliveries, POs + date changes, ATP projections, quality / reservations, API JSON samples |
| `logistics/` | TMS + carrier visibility platform + ServiceNow + retail-ops IBT tool | TMS loads, carrier events (UTC), customs declarations, incidents + work notes, IBT history, lane matrix |
| `marketing/` | Excel calendar, agency media plan + PDF report, Salesforce exports, PR tracker, social listening SaaS | campaign calendar, media plan, agency flash report, CRM campaigns/members, clienteling notes, waitlists, seeding log, social alerts |

| `ecommerce/` | Shopify-like analytics export + SFCC-like custom objects | daily online sales by country x variant, notify-me requests, availability log, site search |

| `agents/` | A2A agent cards, OpenAPI 3 YAML, JSON examples, JSONL conversation log | interfaces of warehouse/logistics/marketing/planning agents; mock server in `generator/systems/mock_agents/server.py` |

## Store / ID crosswalk (truth)

- Internal id (BI, POS, emails) `MIL01` ↔ SAP plant `WERKS` = country prefix + sequence in internal order
  (IT 10xx, FR 11xx, CH 12xx, GB 13xx, DE 14xx, ES 15xx, NL 16xx, DK 17xx, AE 18xx, US 20xx, CA 21xx, JP 30xx, KR 31xx,
  CN 32xx, HK 33xx, TW 34xx, SG 35xx, AU 36xx; e.g. MIL01 1001, ROM01 1003, PAR01 1101, ZRH01 1202, LON02 1302, SEL01 3101, SYD01 3601).
- TMS ship-to `KUNNR` = `00000` + (70000 + WERKS) → MIL01 `0000071001`, SEL01 `0000073101`.
- CRM (Salesforce `Store__c`) codes follow **CRM go-live order**, NOT internal order: IT01 MIL01, IT02 ROM01, IT03 MIL02, IT04 VEN01,
  IT05 CRT01, IT06 COU01; FR01 PAR01, FR02 CAN01, FR03 PAR02; US01 NYC01, US02 BHS01, US03 NYC02, US04 MIA01, US05 ASP01;
  JP01 TYO01, JP02 OSA01, JP03 TYO02; **KR01 SEL02, KR02 SEL01**, KR03 BUS01; others country+01/02 in internal order.
  A naive "same order as internal" mapping swaps Seoul Cheongdam and Hyundai Apgujeong, Rome and Rinascente, etc.
- DCs: DC-IT-CSG = plant IT10, DC-US-NJ = US20, DC-HK-TKO = HK30 (3PL site `TKO-3`, client `MONC01`).
- SKU: internal `J20931A00012-999`; SAP `MATNR` = `J20931A00012999` + size in `J_3ASIZE`; 3PL item code
  `MC` + last 8 chars of style + colour + 2-digit 1-based size index (MAIRE black size 0 = `MC31A0001299902`) + EAN;
  e-com variant `J20931A00012-999-1` (TU items mostly without suffix; WeChat channel rows carry the EAN).

### Planted crosswalk problems (`reference/store_code_crosswalk_MDM.csv`)
- CRM code missing for CRT01 and SYD01 (they are IT05 and AU01).
- MAD01 TMS ship-to is stale (`0000071599`, last update 2024); the TMS/MSEG/carrier feeds use the correct `0000071501`.
- BUS01 Zendesk tag written as `store_busan_centum` in MDM, Zendesk itself uses `store_busan_shinsegae_centum_city`.
