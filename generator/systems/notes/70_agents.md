## Agents (`agents/`) and mock server

- `agent_cards/*.json` – A2A AgentCards (protocolVersion 0.3.0) for `warehouse-agent` (OAuth2 client credentials, scopes wms.read/wms.reserve,
  JSON-RPC), `logistics-agent` (API key header `X-Api-Key`, HTTP+JSON preferred, push notifications), `marketing-agent` (beta, OAuth2 + mTLS,
  drafts only, no PII), `planning-agent` (JWT bearer). Each declares skills, examples, endpoints and operational limits (rate limits, cut-offs,
  3PL data latency). Identifier "dialects" differ: warehouse = SAP plant/MATNR, logistics = SAP plant or TMS ship-to and UTC, marketing = CRM
  store codes, planning = internal ids or SAP plants.
- `openapi/*.openapi.yaml` – OpenAPI 3.0.3 per agent: warehouse (`GET /stock`, `GET /atp`, `GET /inbound/purchase-orders/{ebeln}`,
  `GET /quality-stock`, `POST /reservations`), logistics (`GET /shipments/{ref}/tracking`, `GET /lanes`, `POST /transfer-requests`,
  `GET /customs/holds`), marketing (`GET /campaign-calendar`, `GET /waitlists`, `POST /clienteling-message-draft`, `GET /social-alerts`),
  planning (`GET /replenishment-parameters/{store}`, `POST /replenishment-proposal`, `GET /allocation-plan`, `GET /otb`).
- `examples/*.json` – request/response pairs produced by the same handlers as the mock server.
- `inter_agent_conversations.jsonl` – 54 lines (27 request/response pairs) of A2A JSON-RPC `message/send` traffic, UTC, Sep 8 → Oct 22,
  generated by replaying the handlers at the historical date (so every answer is consistent with what systems knew then).

### Mock server (`generator/systems/mock_agents/server.py`, logic in `handlers.py`)
`.venv/bin/python generator/systems/mock_agents/server.py --port 8088` → REST under `/{warehouse|logistics|marketing|planning}/v1/...`,
A2A JSON-RPC under `/{agent}/a2a` (`message/send`, skill in `message.metadata.skill`, arguments in a `data` part), agent cards under
`/{agent}/.well-known/agent-card.json`. Reads only `generated/sources/` (override with `DATA_ROOT`); every endpoint accepts `asOf` to replay the past.
Rules implemented in `lg_transfer_request`: lane IBT policy, closed stores (COU01 season, STM01 from Oct 19, CRT01 Mon–Thu in October),
source stock from `store_stock_daily` (previous EOD), pickup cut-off & weekends, required-by date, cost = fixed + per-unit.
`pl_replenishment_proposal`: order-up-to on the latest Monday forecast run (event-blind) × optional demand multiplier, capped by DC ATP.
